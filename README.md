# Telkom University Company Profile - Praktikum 
 
Project simulasi HTML, CSS, PHP native, MySQL/MariaDB, dan Git.

Perubahan ini dibuat dari simulasi Laptop B.

Perubahan dari Laptop A untuk simulasi push ditolak

Prubahan dari Laptop B untuk simulasi push ditolak.

## Cara Menjalankan Project

1. Jalankan Apache dan MySQL melalui Laragon.
2. Pastikan database `telkom_profile` sudah tersedia.
3. Simpan project di folder `D:\laragon\www\telkom-company-profile`.
4. Buka project melalui browser.
